# Developer Documentation: MySimkari Sync

## Setup Instructions

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn
- Windows OS (required for full functionality including Office COM features)
- Microsoft Office installed (Word, Excel, PowerPoint)

### Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

### Development Mode
Run the application in development mode with hot-reload:
```bash
npm run dev
```

### Building for Production
To build the application for production:
```bash
npm run build
```
The output will be located in the `dist` and `dist-electron` folders, with the installer generated by `electron-builder`.

## Key Development Concepts

### 1. IPC Communication
The app uses `ipcMain.handle` in `electron/main.ts` and `window.ipcRenderer.invoke` in the Vue components.
- **Example**: `select-folder`, `parse-file`, `sync-data`.

### 2. Database Management
- Database is initialized in `main.ts` using `better-sqlite3`.
- The database file is located in the user's data directory: `app.getPath('userData')/mysimkari.sqlite`.

### 3. Sync Mechanism
- The `sync-data` handler performs a multi-step process:
  1. Fetch CSRF token.
  2. Read local file into buffer.
  3. Create `FormData`.
  4. POST to MySimkari API using the captured cookies.

### 4. PowerShell Integration
- Used for Office tasks. If you are developing on Mac/Linux, these features will not work and may need mocks or alternative implementations.
